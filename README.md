# FOLD / UNFOLD

A minimalist puzzle about folding the board itself to reach the goal.

You control a single piece on a small grid.  
By folding and unfolding the board along a central seam, your move can be carried across space.

No timers. No score pressure. Just deliberate moves and spatial reasoning.

## Play
- Download `index.html` and open it in any modern browser  
- Or play online via GitHub Pages (link below)

## Features
- 9 handcrafted levels
- Fold-and-carry puzzle mechanic
- Undo at any time
- Keyboard and touch controls
- Runs as a single HTML file

## Controls
- Arrow keys — Move
- F — Fold / Unfold
- Z — Undo
- R — Reset level
